## Selected Projects

### Acoustic and Vibrational Detection of Coronary Artery Disease

Exploratory MSc research investigating the use of chest-surface acoustic and vibrational signals for future non-invasive CAD pre-screening.

The project combined sensor characterisation, signal processing, public cardiac datasets and healthy-volunteer recordings within a reproducible Python analysis framework.

**Python · Signal Processing · Biomedical Data · Sensor Analysis**

[View project](https://github.com/silviiavalls/An-exploratory-framework-for-acoustic-and-vibrational-detection-of-coronary-artery-disease-)

### Multimodal Probe Design for Infant Neuroimaging

Computational design and geometric validation of multimodal EEG, fNIRS and fDCS probes for infant neuroimaging.

Developed a Python framework to evaluate probe geometry, sensor placement and source-detector configurations under physical design constraints.

**Python · Computational Geometry · Neuroimaging · Medical Devices**

[View project](https://github.com/silviiavalls/Multimodal-Infant-Neuroimaging)
